# 版本迭代记录

## 当前版本：1.0.2

- tag：`v1.0.2`
- 状态：已正式发布
- Release：https://github.com/maxzrb/hill-mpv-launcher/releases/tag/v1.0.2
- Release asset：`hill-mpv-launcher-v1.0.2-win-x64.zip`
- ZIP SHA-256：`32f741c6ad37e185496dc410d35ac151d29e83b353aa8b65f0f63e38d982a6e9`
- 发布日期：2026-09-24
- 目标平台：Windows x64
- 兼容性：同时支持 Hills Lite 1.4.1 旧调用格式与 1.5.3 起的 `--playlist=memory://` 内联播放列表格式；需要本机可用的 Windows x64 mpv；部分 Emby 服务器要求会话地址携带 `UserId`
- 迁移说明：可直接覆盖旧版 `mpv-launcher.exe`；`launcher.ini` 新增可选 `[emby] user_id`，留空时自动读取 Hills 当前登录会话；本机 `launcher.ini` 与日志不要提交或分享。
- 主要内容：适配 Hills Lite 1.5.3 新版调用格式（逐行解析 `--playlist=memory://`，只替换条目里的 115 CDN 地址并保留 playlist 结构）、同一 playlist 内多集按条目分别匹配、Emby 会话地址补充 `UserId` 修复起播 403、日志新增 `playlist_entry`/`span`/`entry_title` 诊断字段。
